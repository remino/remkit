# ghostty

Copy a theme file into `~/.config/ghostty/themes/`, then select it by name:

~~~ini
theme = Crimson
~~~

Each theme preserves the Display P3 colors from its iTerm source and carries
across compatible settings from `iterm/profiles/Rem.json`: the font, size,
80×40 initial grid, cursor behavior, xterm-256color, transparency, blur, and
bright bold text.
