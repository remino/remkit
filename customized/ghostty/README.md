# ghostty

Copy a theme file into `~/.config/ghostty/themes/`, then select it by name:

~~~ini
theme = Crimson
~~~

Each theme carries across compatible settings from `iterm/profiles/Rem.json`:
the font, size, 80×40 initial grid, cursor behavior, xterm-256color,
transparency, blur, and bright bold text. Cyberwave preserves its original
Display P3 base palette, maps its Light regular face to Sarasa's native Bold
and Bold Italic faces, and uses lifted bright ANSI variants so both text weight
and SGR bright colors remain distinct.
