# Snippets

Small, standalone examples intended to be copied and adapted. Check each
file's comments before using it in production.

| Directory | Purpose | Runtime / compatibility |
| --- | --- | --- |
| `asm/` | A minimal hello-world assembly program. | Requires a platform-specific assembler and linker. |
| `bash/` | Bash argument-handling examples. | Bash; not POSIX `sh`. |
| `c/` | Basic C programs for I/O, strings, arrays, and options. | C compiler and standard library. |
| `cron/` | Crontab schedule examples. | Vixie cron-compatible crontab. |
| `css/` | Reusable layout, typography, debugging, color-scheme, and accessibility rules. | Modern CSS; individual files note any feature requirements. |
| `fixtures/` | Small text fixtures for testing examples. | Plain text. |
| `haml/` | Haml looping example. | Haml compiler. |
| `html/` | HTML boilerplates and focused examples, including redirects, grids, social metadata, and fullscreen. | Modern web browsers; `html-css-js.html` has no JavaScript behavior by default. |
| `js/` | Browser and Node.js utilities for DOM, async work, data, files, and platform helpers. | Check imports and browser APIs in the individual file. |
| `jxa/` | JavaScript for Automation sample. | macOS `osascript -l JavaScript`. |
| `licenses/` | Reusable license text and notes. | Plain text. |
| `macos/` | macOS system-configuration command snippets. | macOS; may require administrator privileges. |
| `md/` | Markdown document templates. | Plain Markdown; `README.template.md` is a project README starter. |
| `nginx/` | Nginx redirect configuration examples. | Nginx configuration context; validate with `nginx -t`. |
| `pug/` | Pug looping example. | Pug compiler. |
| `python/` | Small HTTP/HTTPS server and Unicode utilities. | Python 3. |
| `ruby/` | Ruby filename/extension utility. | Ruby. |
| `sass/` | Sass syntax and layout examples. | Sass compiler. |
| `sh/` | POSIX shell patterns for arguments, files, signals, and external commands. | POSIX `sh`; individual commands may need installed tools. |
| `sql/` | Date-formatting SQL examples. | MySQL/MariaDB syntax. |
| `txt/` | Plain-text formatting example. | Plain text. |
| `xml/` | XML, DTD, XSLT, CSS, and script example files. | XML/XSLT-capable tools or browsers. |
